How Physical Modelling Works

Physical modelling synthesis simulates the physics of real instruments instead of manipulating waveforms abstractly. The Karplus-Strong algorithm models a plucked string using a delay line with feedback.

Karplus-Strong algorithm: 1. Fill a short buffer with random noise (the "pluck") 2. Feed the buffer into a recirculating delay line 3. Each pass through a low-pass filter (string stiffness / damping) 4. Slightly reduce gain each cycle (energy loss) String frequency = 1 / delay_time Decay ∝ feedback gain × filter cutoff

The delay line length sets the pitch. The low-pass filter smooths out high frequencies over time — mimicking how real strings lose high-frequency energy faster than low-frequency energy.

Pluck position is modelled by changing the filter cutoff: plucking near the bridge (bright) vs near the middle (darker, rounder tone).
